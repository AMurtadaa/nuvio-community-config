Nuvio Simple Config

Keep each streaming service's browsing categories together. No “More Browsing” tile, VM, hosted cache, or custom app build. This page prepares an import locally; it does not sign in or change your account.

1. Back up before you begin

In Kaptain Studio, select your profile and export a backup. Use a spare profile for the first test. The generated import replaces the target profile's collection list. Keep your backup private.

You need your existing native TMDB/metadata and playback setup. Optional charts need your own TopX addon. See the complete guide or open that file on GitHub.

2. Choose the supplied template

Choose the public template, not your private account backup. Your browser reads this file locally.Find the top-level numeric profileId in your own Studio backup, opened locally in a text editor. Profile name and profile ID are different.

3. Choose optional extras

Install your own configured TopX addon first. Enter its manifest ID, not its URL or a key. Leave blank to omit the 20 chart sources and browse without TopX.Enable only if you installed the BetterPosters addon with manifest ID community.betterposters. This is separate from using a Bttr poster URL.This replaces Home preferences. With TopX: Movies Top 10, Series Top 10, Streaming Services. Without TopX: Streaming Services first. Leave off to arrange Home yourself.This changes the supplied TV layout/hero/poster settings. Leave off to keep your current appearance. Client versions differ; it cannot force GIF or hero support.

4. Generate and download

Nothing has been changed.

In Studio → Backups & Updates, import the Studio file, then click Restore on the imported item. Fully close and reopen Nuvio. The page never uploads the file or applies it for you.

Direct category loading can be slower on low-powered devices than the cached VM version. Short shelves, lazy loading and scroll behavior depend on your Nuvio client. This package does not promise continuous horizontal loading.
