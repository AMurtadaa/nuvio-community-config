My private Nuvio recovery kit

Your configured addon links and saved keys stay on this computer. The saved vault is encrypted for your Windows user. This page does not send anything to Nuvio or other services.

This vault opens automatically on this Windows account. It is not a portable backup for a new PC or a Windows reinstall. Keep credentials in your own password manager too. Anyone using your unlocked Windows session can open it.

Opening local vault…

1. Complete the backup once

Working addon links are already saved with their embedded credentials. TMDB is separate: enter the working key here once if it is missing. Saving here updates only this local vault.

2. Save a portable backup for a new computer

Do this after saving the missing keys above. This encrypted file works with the offline portable.html helper from the GitHub package. Keep its password separately; there is no password reset.

3. Restore the layout

Use this file for folders, Home order and saved settings. It excludes addons and provider keys so Kaptain cannot redact and reinstall them. The import replaces those sections on the selected target.

4. Restore configured addons without typing keys

On Nuvio’s account website, select the intended profile. Use Edit for an existing matching entry or Add Addon for a missing one. Copy its configured URL below and paste it there. Check the name before saving; keep the displayed order. The copy buttons include credentials but never display them.

Do not import addon links through Kaptain backup files: its snapshot process can redact keys. Do not paste these links into chat or GitHub.

5. Finish each profile and device

  1. In Windows Nuvio → Settings → General → Integrations → TMDB Enrichment: paste the saved TMDB key and Save.
  2. Reauthorize Trakt or other OAuth accounts where required. This kit does not save Nuvio login sessions or passwords.
  3. Reopen Nuvio and check Genres, Mood & Vibes, Based on, service shelves, Top 10 art and playback.

Saved links depend on their providers and active subscriptions. Revoked or expired credentials must be updated. Existing Oracle hosting is separate; restoring this profile does not rebuild the VM.
