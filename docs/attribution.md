# Sources and third-party rights

This repository packages a community-authored configuration and original helper code. It is not affiliated with the services below.

- [NuvioMedia](https://github.com/NuvioMedia): Nuvio clients; client behavior differs by platform and version.
- [Kaptain Studio](https://kaptain.stream/studio): profile/collection configuration and much of the referenced collection artwork, including `art.kaptain.stream`.
- [TopX](https://topx.stremio-italia.eu/): catalog configuration and chart/rank artwork. Create your own configuration; the owner's saved endpoint is not distributed.
- [Bttr / BetterPosters](https://btttr.cc/configure): poster styling and global catalogs. IMDb is selected as the rating source; this does not guarantee immediate score parity with another metadata provider.
- [TMDB API](https://developer.themoviedb.org/): catalog discovery and artwork references. This product uses the TMDB API but is not endorsed or certified by TMDB. Native clients and API integrations retain their own attribution, branding and API requirements.
- [Trakt API](https://trakt.docs.apiary.io/): saved list references; configure any required native Trakt integration in your own client.
- [Stremio addon protocol](https://stremio.github.io/stremio-addon-sdk/api/responses/manifest.html): catalog and manifest conventions.
- [wsrv.nl](https://wsrv.nl/): external artwork proxy referenced by cover URLs.

Other remote artwork URLs reference their original hosts. Their inclusion is a URL reference, not a grant of redistribution rights or an availability guarantee. Public catalog/list IDs are query references, not account credentials. Review provider terms and current quotas before wider hosting; no unlimited free hosting or commercial license is promised.
