Set up Nuvio again, safely

Restore your working layout, then connect your services. This helper runs on your computer. It never signs in, sends your backup anywhere, or changes your account.

Full instructions on GitHub · For a first-ever installation, follow the package links in that guide.

1. Choose a working backup

Extract the entire GitHub ZIP before opening this page. In Kaptain Studio → select the working profile → Backups & Updates → Export backup file. Keep this original privately.

Unlike the simple-config generator, this recovery helper expects your private backup. It reads the selected file locally. Credentials are not requested.

2. Choose what to restore

Export the target profile and find its top-level profileId. The ID is a number, not its name. Use a spare profile first.

Folders are included. Their IDs and source references are preserved.

Appearance includes an allowlist of layout, theme, trailer, badge, and poster settings across saved platforms. Playback, provider settings, credentials, and watch history are excluded. Unrecognized custom poster URLs are omitted.

3. Check and download

No file has been read. No account changes will be made.

In Kaptain Studio, select the target profile → Backups & Updates → Import backup file → select this new file → Restore the imported item. Read its change summary before applying.

Addon URLs and service keys are NEVER included. A backup may replace keys with “REDACTED.” That is not a usable token. Importing this helper’s file cannot overwrite your addon list or provider-key settings.

4. Connect each profile

  1. On Nuvio’s account site, select the exact profile. Install your own configured addons. On a working account, keep existing addon URLs.
  2. If needed, use the addon’s Edit button to replace a placeholder in its URL with your current credential. Never paste keys into GitHub or chat.
  3. In Windows Nuvio: Settings → General → Integrations → TMDB Enrichment. Enter your own TMDB API Key (v3 auth) if required, then Save. Do not use the longer read-access token in an API-key-only field.
  4. Connect Trakt or other integrations only where your selected sources require them. Saved appearance does not connect these services.
  5. Reopen Nuvio and select the target profile. Repeat connection checks on every device.

5. Pass the checks before calling it finished

These are manual checks, not automatic results. If something fails, use the matching troubleshooting section in the guide; do not reset the whole profile.

Keep generated imports private. They contain your personal layout and service references even though this helper excludes addon URLs and credential settings. A layout import cannot rebuild a VM or provide another person’s subscriptions.
